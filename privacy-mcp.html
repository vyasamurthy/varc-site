Privacy Policy

Venture Vertex LLCEffective: September 20, 2026Applies to: varc-mcp connector

What This Policy Covers

This Privacy Policy describes how Venture Vertex LLC handles data when you use the VARC MCP Connector — a Model Context Protocol server that exposes VARC behavioral governance tools to Claude agents operating in regulated enterprise environments.

The connector exposes six tools: session governance (GIM), pre-action policy checking (Policy Bus), cryptographic tool-call commitment and verification (TCIV), behavioral scoring (BEV), and HITL hold status.

Data We Collect

When the VARC MCP Connector is invoked, the following data passes through to your organization's VARC tenant:

  • Agent identifiers — the agent_id and session_id you supply in each tool call
  • Tenant identifier — your organization's VARC tenant ID
  • Tool call parameters — tool name, arguments, and action description
  • Task objectives — the task_objective string passed to varc_session_start
  • Behavioral flags — boolean indicators passed to varc_bev_score
What we do not collect: The connector does not collect, store, or process end-user personal data, conversation content, or Claude model outputs. No data is retained by the connector itself.

How Data Is Used

Data transmitted through the connector is used solely to operate VARC governance functions: deriving behavioral contracts, evaluating actions against policy, creating cryptographic attestation records, scoring behavioral dimensions, and checking HITL hold status. Data is not used for model training, advertising, or any purpose outside your governance workflow.

Data Storage and Retention

  • The connector is stateless — no data is stored locally between calls
  • Governance records are stored in your organization's VARC tenant on Google Cloud Platform, us-central1
  • You own and control all governance records written to your tenant
  • Default retention: 90 days, configurable per tenant
  • You may delete your tenant data at any time by contacting support

Third-Party Services

The connector transmits data to one service: the VARC API at api.varc.live, operated by Venture Vertex LLC. No other third-party services receive connector data.

Authentication and Security

  • API keys are transmitted over HTTPS only and never logged by the connector
  • All connections use TLS 1.2 or higher
  • Keys are scoped to individual tenants

Your Rights

  • Access all governance records via the VARC API or OpsCenter
  • Export governance records in JSON format at any time
  • Request deletion of all data associated with your tenant

Changes to This Policy

Material changes will be communicated via the VARC release notes at github.com/vyasamurthy/varc-mcp. Continued use constitutes acceptance of the updated policy.
